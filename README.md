# Задания спринта 8

Заполните `realization.py` в каталоге задания и выполните:

```bash
python3 submit.py
```

Нужен Python 3.9+

Сервис вычисляет поддерживаемые выражения DataFrame на Spark с тестовыми данными Kafka/PostgreSQL. Произвольный Python, UDF, SQL-выражения и пользовательские файлы сервер не выполняет. Функции, имена выходных DataFrame и запуск query сохраняйте как в заготовке.
Сервис не проверяет доступность вашей Kafka/PostgreSQL или учётные данные. Для практической работы подключение настраивается отдельно.

`USER_HOST` и `TOPIC_NAME` в `settings.py` относятся к учебным ресурсам, не к адресу сервиса. Клиент не импортирует этот файл или решение; локальные Spark и копия репозитория тестов для отправки не нужны.
